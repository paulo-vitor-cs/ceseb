# CESEB — Projeto 1: calculadora de financiamento

Projeto desktop em C++ para Windows e Linux, iniciado a partir da proposta **Mortgage Software Design and Testing**. Tecnologias exigidas: C++, Google Test e GitHub. Desenvolvimento conduzido pelo fluxo Mikoshi Design.

**Estado atual:** descoberta em rascunho. O aplicativo ainda não foi implementado; não há build ou teste de produto executado.

- [Proposta de escopo e escolhas abertas](.mikoshi/brain/sessions/1-mortgage-desktop/documents/1003/r1-discovery-proposal.md).
- [Pedido humano original](.mikoshi/brain/sessions/1-mortgage-desktop/documents/1001/r1-human-request.md).
- [Leitura atribuída da imagem](.mikoshi/brain/sessions/1-mortgage-desktop/documents/1002/r1-image-evidence.md).
- [Decisões iniciais](.mikoshi/brain/sessions/1-mortgage-desktop/decisions/1004/r1-initial-project-choices.md).

A proposta é uma janela com principal, taxa e prazo, cálculo de parcela/total/juros, validação de entradas e interface simples e moderna. Qt 6 Widgets e CMake são opções propostas. As escolhas materiais serão confirmadas antes do design e dos planos executáveis.

Próximo passo: gate humano da descoberta. A futura entrega inclui aplicativo, testes nas duas plataformas, documentação e relatório técnico rastreável. Ainda não foi selecionada uma licença.
