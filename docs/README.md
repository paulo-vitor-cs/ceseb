# Calculadora Financiamento — documentação

Aplicação desktop local em C++20 e Qt Widgets para comparar Price e SAC, com taxa anual nominal ou efetiva, interface em português e valores em reais.

## Relatório e apresentação

- [Relatório técnico em PDF](relatorio-do-projeto.pdf): nove páginas sobre o Modelo V, especificações, requisitos, decisões, implementação e validação.
- [Apresentação HTML](apresentacao-do-projeto.html): dez slides com diagramas, exemplos de testes e notas do apresentador. Baixe o arquivo e abra-o no navegador.

Mantenha o PDF e o HTML na mesma pasta para usar o link do relatório disponível na apresentação.
